# 迷你商城需求说明（模拟真实非标 PRD）

> 说明：本需求故意模拟实际工作里“不够完整、没有标准编号”的飞书/语雀文档风格，其中有两处模糊口径，演示 AI 如何先向人提选择题拍板。

## 一、用户登录
- 用户通过用户名和密码登录商城，登录成功后进入商品列表页。
- 账号或密码错误时提示“账号或密码错误”。

## 二、商品浏览与加购
- 商城展示可用商品列表（包含商品名称、单价、库存）。
- 已登录用户可将商品加入购物车，每次加购至少 1 件；如果未登录，不允许加入购物车。
- 【待确认 1】加购数量超过当前商品库存时，是直接拒绝并提示“库存不足”，还是允许先加购、结算时再校验？

## 三、购物车与结算下单
- 用户进入购物车页面后，可以看到已加购的商品及合计金额。
- 购物车为空时显示“购物车为空”，不展示结算按钮。
- 用户点击“去结算”提交订单后，系统生成订单编号、扣减并清空当前购物车，页面提示“下单成功”。
- 【待确认 2】如果用户连续点击两次“去结算”，是否做防重提交拦截？
